# server/http

Роутер (chi), middleware и хендлеры REST API.

- **Загрузка — отдельная группа маршрутов**: свой предел времени (`ReadTimeout`,
  с запасом на заливку 10 MB по медленному каналу) и ограничитель тела
  `MaxBytesReader`. Остальные маршруты живут под коротким `RequestTimeout`.
- **Коды ответов выбирает одна функция** — `mapError`; хендлеры своих статусов
  не изобретают. Всё нераспознанное — 500 с общим текстом, подробности только
  в лог. Из неочевидного: `ErrInvalidTransition` → 409 (состояние сменил другой
  процесс, повтор осмыслен), истёкший дедлайн → 504.
- **Раздача — стриминг** `io.Copy` из хранилища, тело в память не буферизуется.
  `If-None-Match` → 304; сравнение ETag слабое, потому что содержимое по одному
  ключу не меняется — новая загрузка порождает новый аватар. Заглушка помечается
  заголовком `X-Avatar-Default: true`.
- **`X-Request-ID`** принимается от клиента, только если это печатаемый ASCII
  разумной длины (значение попадает в каждую запись лога), иначе генерируется
  свой; возвращается в ответе тем же заголовком.
