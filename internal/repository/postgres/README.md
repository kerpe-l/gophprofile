# repository/postgres

Метаданные аватаров в PostgreSQL на pgx.

- **Мягкое удаление — во всех запросах.** Каждый запрос отбирает только
  `deleted_at IS NULL`; удалённый аватар неотличим от несуществующего,
  оба дают `domain.ErrNotFound`.
- **Переходы статусов проверяет сама база.** `UPDATE` отбирает строку по `id`
  и списку разрешённых исходных статусов; список задаёт домен (`AllowedFrom`).
  Проверка отдельным чтением не годится: между чтением и записью статус успевает
  сменить другой процесс. Если `UPDATE` не затронул строк, причина уточняется:
  живой записи нет — `ErrNotFound`, есть — переход запрещён, `ErrInvalidTransition`.
- **Перебор — ленивый.** `ListByUser` и `SelectStuck` возвращают `iter.Seq2`:
  вызывающий прерывает перебор на первой ошибке, не вычитывая остальное.
- **`SelectStuck`** — выборка для reconciler'а: `uploaded` + `pending`,
  не менявшиеся до переданной отсечки. Момент отсечки задаёт вызывающий — часы
  принадлежат ему, иначе выборку не проверить тестом без реального ожидания.
  Под запрос заведён частичный индекс `idx_avatars_status`.

Интеграционные тесты — на testcontainers, под `//go:build integration`:
`go test -tags=integration ./...`.
