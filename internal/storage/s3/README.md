# storage/s3

Оригиналы и миниатюры в S3-совместимом хранилище (в окружении — MinIO)
через minio-go.

- **Бакет создаёт инфраструктура.** Приложение на старте только проверяет его
  наличие: рантайм с правом создавать бакеты при опечатке в имени молча завёл бы
  новый пустой вместо того, чтобы упасть.
- **Дедлайн ставится в одном месте** (`withDeadline`) и не перебивает дедлайн
  вызывающего. Исключение — `Get`: его тело читается после возврата из метода,
  и дедлайн операции оборвал бы стриминг; предел ему ставит транспорт.
- **Транспорт свой, с пределом на каждую фазу запроса** — установка соединения,
  TLS-хендшейк, ожидание заголовков ответа. У `http.DefaultTransport` двух
  последних нет, и зависшее хранилище держало бы вызов до дедлайна контекста
  вместо быстрого отказа и повтора.
- **Повторы — `MaxRetries: 3`, явно.** Иначе поведение менялось бы вместе
  с версией библиотеки.
